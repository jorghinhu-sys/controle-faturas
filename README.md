# Controle de Faturas

App web instalável para acompanhar faturas de cartão de crédito, parcelas e limite disponível.

- Funciona sem internet depois da primeira abertura.
- Os dados ficam só no aparelho (armazenamento do navegador). Use **Dados > Salvar backup** de tempos em tempos.
- Nenhum dado é enviado para servidor nenhum.

## Instalar no iPhone

1. Abra o endereço do app no **Safari**.
2. Toque em Compartilhar e em **Adicionar à Tela de Início**.
3. Deixe "Abrir como Web App" ligado.

## Atualizar

Ao publicar uma mudança, troque o valor de `VERSION` em `sw.js` para o celular baixar a versão nova.
